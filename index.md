## 🛠️ How to Use

### First Time Setup
1. After opening `index.html`, you'll see a clean dashboard interface.
2. No account creation needed—all data is stored locally in your browser.
3. Start by adding your first content task using the "Add Task" button.

### Managing Tasks
- **Add a Task:** Click the "+" icon, enter task details (title, description, due date, priority).
- **Edit a Task:** Click on any task to modify its details.
- **Mark Complete:** Check the box next to a task to mark it done.
- **Delete:** Remove tasks you no longer need.

### Setting Objectives
- Navigate to the "Objectives" section.
- Click "New Objective" to define a goal (e.g., "Publish 4 blog posts this month").
- Add sub-tasks or milestones to track progress.

### Using Notes
- Open the "Notes" panel.
- Click "New Note" to start typing.
- Notes auto-save as you type.
- Use tags or categories to organize your notes.

### Customizing Your Dashboard
- Rearrange widgets by dragging them.
- Change color themes from the settings menu.
- Set your work hours and break reminders.
